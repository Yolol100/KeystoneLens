# KeystoneLens Bridge

The maintained World of Warcraft addon source is `addon/KeystoneLensBridge/`.

The CurseForge upload ZIP is generated from the canonical tagged source by the release workflow. Generated ZIPs are not committed to `main`. The archive contains one top-level `KeystoneLensBridge/` folder and a matching `KeystoneLensBridge/KeystoneLensBridge.toc`.

Use the version and interface metadata from the TOC as the addon release contract. Select only game versions validated on the released Retail client, and use Beta/preview distribution until the live acceptance gate has passed.
